# ForestGuard – Protect Our Forests (plain HTML/CSS/JS)

Educational website about illegal forest activities in India. No build step.

Files: `index.html`, `style.css`, `data.js` (all content), `script.js` (pages and navigation).

## Run locally
Open `index.html` in a browser, or run `python -m http.server` in this folder and visit http://localhost:8000.
Fonts and icons load from Google Fonts and jsDelivr, so you need an internet connection.

## Deploy with GitHub Pages
1. Upload these files to the root of a GitHub repository.
2. Repository Settings → Pages → Source: "Deploy from a branch" → Branch: `main`, folder `/ (root)` → Save.
3. Your site appears at `https://YOUR-USERNAME.github.io/REPO-NAME/` after a minute.
Netlify and Vercel also work: no build command, publish directory is the repo root.

## Notes
- The Report page is a demonstration. Nothing is sent or saved.
- Statistics are from ISFR 2023 (Forest Survey of India). Verify them and the law summaries against official sources before presenting.
